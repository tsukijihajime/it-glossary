# IT用語辞書サイト 設計書

作成日: 2026-11-18

## 目的

新入社員や非技術者（営業・総務など）が、業務で耳にする IT 用語の意味を手早く調べられる共通辞書を提供する。

## 前提・制約

- SharePoint Online のドキュメントライブラリに置いた HTML はダウンロード扱いとなり、スクリプトも実行できないため採用しない。
- GitHub Pages（公開リポジトリ）でホストする。サイトは全世界から閲覧可能になるため、**一般的な IT 用語のみ**を掲載し、社内固有の略語・顧客名・案件名は掲載しない。
- Teams からはチャネルの「Web サイト」タブに Pages の URL を登録して参照する。

## 目標 / 非目標

- 目標: 非技術者が読んで分かる平易な解説、高速な検索、分野別の閲覧、データのインポート/エクスポート。
- 非目標: ログイン、サーバー側での編集機能、技術者向けの詳細解説。
- アンチゴール: 専門用語だらけの解説、ビルド環境が必要で非エンジニアが保守できない構成。

## 検討した方式

| 方式 | 評価 |
|------|------|
| SharePoint リスト | スクリプト不要で社内限定にできるが、ユーザー判断で Git 方式に変更 |
| SPFx Web パーツ | テナント管理者の展開が必要 |
| GitHub Pages 静的サイト | **採用**。費用ゼロ、Git で履歴管理、ビルド不要 |

## 構成

```
index.html        画面
style.css         スタイル（ライト/ダーク対応）
app.js            検索・表示・インポート/エクスポート
data/terms.json   用語データの正本
README.md         運用手順
```

ビルド工程なし、外部ライブラリなし（素の HTML/CSS/JS）。

## 用語データ項目

| キー | 内容 |
|------|------|
| id | 一意キー（英数字） |
| term | 用語 |
| reading | 読み（ひらがな） |
| fullName | 正式名称・略語の展開 |
| category | 分野 |
| summary | ひとこと説明 |
| description | やさしい解説 |
| analogy | 例え話 |
| example | 会話での使用例 |
| related | 関連用語の id 配列 |
| level | 難易度 1〜3 |
| aliases | 別の呼び方・読み方の配列（検索対象。CSV は | 区切り。2026-11-18 追加） |

分野: ネットワーク／セキュリティ／クラウド／開発・プログラミング／データ・AI／ハードウェア・組込み／プロジェクト・業務／よく聞く略語／医療機器・内視鏡（2026-11-18 追加）

## 機能

- インクリメンタル検索（用語・読み・正式名称・解説が対象。ひらがな/カタカナ、全角/半角、大文字/小文字、長音・中黒・小書きかなの有無を同一視）
- あいまい検索：一致 0 件のとき、用語・読み・正式名称との編集距離が小さい用語を「もしかして」として最大 10 件表示（3〜5 文字は 1 文字違い、6 文字以上は 2 文字違いまで。2 文字以下は対象外）
- 分野タブ、難易度フィルタ、お気に入りのみ表示
- 頭文字索引（ABC / あかさたな）
- 詳細表示（関連用語リンクで遷移）、`#term=<id>` による URL 共有
- お気に入り（localStorage）
- 今日の用語（日付から決定的に選択）
- スマホ対応、ダークモード対応

## インポート / エクスポート

- エクスポート: 全件 or 表示中の絞り込み結果を JSON / CSV（UTF-8 BOM 付き、Excel で開ける）でダウンロード。
- インポート: JSON / CSV を読み込み、利用者のブラウザ（localStorage）にのみ追加・上書き。取り込んだ用語には「ローカル」バッジを表示。ローカル追加分の削除ボタンあり。
- 全員に反映するには、管理者がファイルを `data/terms.json` に反映してコミットする（README に手順）。

## 文体

解説は通常の日本語（です・ます調）。新入社員・非技術者が読んで分かるレベル。

## 初期データ

約 120 語（各分野 15 語程度）。
